# Module · 用户洞察 + 真实需求

> Module ID: `user_demand_insight`
> ⬜ **可选** — 适用 archetype: Consumer, B2C




## 这一章要回答什么问题

- 目标用户画像？
- 真实使用场景 / 痛点？
- 替代方案 / 竞品的用户为什么不选？
- 价格敏感度 / 复购率？
- 海外用户 vs 中国用户差异？

## 期望产出

- 用户画像表
- 真实需求 vs PR 故事的对比
- 价格敏感度 / 复购数据

## 信息源

尼尔森 / 凯度 / 招股书用户调研 / 一手访谈

## 主要 pitfalls

避免厂商口径。一手用户访谈最重要。

## Agent Prompt 模板

填入 `templates/agent_prompt.md.j2` 渲染时使用：

```
**章节**：用户洞察 + 真实需求

**这一章要回答的核心问题**：
- 目标用户画像？
- 真实使用场景 / 痛点？
- 替代方案 / 竞品的用户为什么不选？
- 价格敏感度 / 复购率？
- 海外用户 vs 中国用户差异？

**期望产出**：
- 用户画像表
- 真实需求 vs PR 故事的对比
- 价格敏感度 / 复购数据

**主要 pitfalls**：
避免厂商口径。一手用户访谈最重要。

**字数**：4000-8000 字

**关键纪律**：
- 每个数字 ≥ 1 URL 引用
- 不可追溯标 [UNSOURCED] / [INFERRED] / [UNDISCLOSED]
- 软化强判断
- 数学验算两次
- 不写元叙事（"应用 skill 模板"等）

**输出**：写入 `sections/user_demand_insight.md`
**在 reply**：摘要 ≤800 字 + 10 条关键发现
```
