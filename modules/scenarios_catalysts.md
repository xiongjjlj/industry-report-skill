# Module · 关键变量 + 三情景 + Catalyst 日历

> Module ID: `scenarios_catalysts`
> ✅ **必选（适用所有行业）**

## 适用场景
所有行业。压轴章节。

## 这一章要回答什么问题

- 未来 12-24 个月有哪些决定性事件？
- 5-7 个核心变量是什么？
- 三种情景（牛/基/熊）触发条件 / 2030 数字 / 受益受损方？
- 哪些 catalyst 可以在路演时讲明可观察？

## 期望产出

- 核心变量驱动表（变量 / 当前状态 / 关键节点 / 影响范围）
- 三情景对比（触发条件 / 时间表 / 2030 关键数字 / 受益方 / 受损方）
- 12-24 月 catalyst 月度日历
- 情景概率给定为区间（如 30-50%），不是单点

## 信息源

综合所有 sections + 政策时间表 + 财报日历

## 主要 pitfalls

概率不要拍脑袋给单点。每个情景必须有可证伪的触发条件。

## Agent Prompt 模板

填入 `templates/agent_prompt.md.j2` 渲染时使用：

```
**章节**：关键变量 + 三情景 + Catalyst 日历

**这一章要回答的核心问题**：
- 未来 12-24 个月有哪些决定性事件？
- 5-7 个核心变量是什么？
- 三种情景（牛/基/熊）触发条件 / 2030 数字 / 受益受损方？
- 哪些 catalyst 可以在路演时讲明可观察？

**期望产出**：
- 核心变量驱动表（变量 / 当前状态 / 关键节点 / 影响范围）
- 三情景对比（触发条件 / 时间表 / 2030 关键数字 / 受益方 / 受损方）
- 12-24 月 catalyst 月度日历
- 情景概率给定为区间（如 30-50%），不是单点

**主要 pitfalls**：
概率不要拍脑袋给单点。每个情景必须有可证伪的触发条件。

**字数**：4000-8000 字

**关键纪律**：
- 每个数字 ≥ 1 URL 引用
- 不可追溯标 [UNSOURCED] / [INFERRED] / [UNDISCLOSED]
- 软化强判断
- 数学验算两次
- 不写元叙事（"应用 skill 模板"等）

**输出**：写入 `sections/scenarios_catalysts.md`
**在 reply**：摘要 ≤800 字 + 10 条关键发现
```
