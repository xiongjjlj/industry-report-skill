# Module · 价值链分层

> Module ID: `value_chain`
> ⬜ **可选** — 适用 archetype: Manufacturing, Energy, Industrial




## 这一章要回答什么问题

- 行业价值链有哪几层（原料 / 中间品 / 成品 / 应用）？
- 每层的 CR3 / CR5 / 国产化率 / 玩家分布？
- 价值量在哪一层最大？毛利在哪一层最高？
- 中美 / 全球玩家在每层的地位？

## 期望产出

- 价值链全景图 + 每层 CR3 / CR5
- BOM 价值量拆解（如适用）
- 每层 Top 玩家清单
- 国产化率 / 卡脖子环节

## 信息源

依 Phase 3 信息源策略

## 主要 pitfalls

不要为了完整性硬写没意义的层（如 AI 软件没有原料层）。
