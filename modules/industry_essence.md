# Module · 行业本质 + 拐点驱动

> Module ID: `industry_essence`
> ✅ **必选（适用所有行业）**

## 适用场景
所有行业。第一章。

## 这一章要回答什么问题

- 为什么是现在？这个行业过去 12-24 个月发生了什么质变？
- 拐点的底层驱动有几条独立曲线？
- 类比哪个历史拐点（PC / Mobile / EV / AI 大模型）？
- 驱动力是真持续，还是周期性 hype？

## 期望产出

- 3-5 个独立驱动曲线（技术 / 经济 / 政策 / 用户 / 资本等）
- 每条曲线的关键事件 + 时间点
- 拐点判断的可证伪条件（如何知道我们错了）

## 信息源

历史类比研究、行业转折点分析、长期 thesis post

## 主要 pitfalls

不要只列"大势"。每条驱动必须有 2-3 个 specific 事件作锚。
