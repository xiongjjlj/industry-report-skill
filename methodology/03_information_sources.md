# Phase 3 · 信息源策略

> 不同行业的信息源完全不同。"WebSearch + 投行研报"对所有行业的覆盖度差距巨大。

---

## 通用 5 类源（任何行业）

### 1. 顶尖人物的公开发言（最重要）
- **X / Twitter**：创业者 / 投资人最直接的观点
- **博客**：长文 thesis（a16z、Sequoia、Bessemer、Founders Fund 等机构 blog；个人 substack）
- **播客**：Lex Fridman、Dwarkesh、20VC、All-In、Acquired、Invest Like the Best
- **YC AI Startup School**、Stripe Sessions、机构年会 keynote
- **机构 official thesis post**：a16z Future / Sequoia / Bessemer State of the Cloud

### 2. 一手数据源
- 公司 IR 网站 / 年报 / 招股书
- 监管机构（FDA / SEC / 工信部 / BIS / 央行 / FCC / 欧盟委员会）
- 行业协会（IEEE / IFR / 中国半导体行业协会 / CIRA）
- 学术论文（arXiv / PubMed / Nature / Science）

### 3. 数据库
- Crunchbase / PitchBook / CB Insights（融资 / 估值）
- IT 桔子 / 烯牛 / 鲸准（中国一级）
- Bloomberg / Reuters / The Information
- Statista / IDC / Counterpoint / Canalys / IDC / Gartner / IFR
- Wind / Choice / 同花顺 iFinD（中国二级）

### 4. 媒体
- **国际**：FT / WSJ / NYT / The Verge / TechCrunch / Stratechery
- **中文**：第一财经 / 财新 / 36氪 / 晚点 / 经纬张颖 / 智东西 / 量子位
- **行业垂直**：The Robot Report / Embedded.com / FierceBiotech / The Block

### 5. 批评者声音（最珍贵）
- 业内独立工程师 / 分析师的反方观点
- 短线做空报告（Hindenburg / Muddy Waters 等）
- 学术界对产业 hype 的批评
- 同行竞品的 thought leadership（Locus 写"Humanoids not ready for warehouse"）

## 按 Archetype 的信息源策略

### 早期硬科技（具身智能 / 脑机接口 / 量子）
**关键源**：
- 创业者 X：Brett Adcock、Bernt Bornich、Eric Jang、王兴兴、彭志辉、王鹤
- 学者：Sergey Levine、Chelsea Finn、Pieter Abbeel、Russ Tedrake、Yann LeCun、Andrej Karpathy
- 投资机构 blog：a16z American Dynamism、Sequoia AI Ascent、NVIDIA Inception
- 论文：arXiv (cs.RO, cs.LG)
- 播客：Dwarkesh、Lex Fridman、Sequoia Training Data
- 批评者：Scott Walter (Figure teleop 质疑)、Locus / Symbotic 的 thought leadership

### AI 软件（LLM / Agents / Coding）
**关键源**：
- 创业者 X：Sam Altman、Dario Amodei、Aravind Srinivas、Logan Kilpatrick、Brett Taylor
- 投资人 thesis：a16z (AI 系列)、Sequoia 2026 essay、Bessemer State of the Cloud
- benchmark：SWE-bench / HumanEval / MMLU 公开 leaderboard
- 用户 review：G2、Product Hunt、Reddit (r/LocalLLaMA, r/cursor)
- 批评者：Gary Marcus、Yann LeCun（LLM 限制论）

### 制造业（储能 / 光伏 / 半导体）
**关键源**：
- 行业研报：高工产研 / GGII / Wood Mackenzie / SNE Research / IEA / EVtank
- 数据：USGS / IEA / IRENA / 中国汽车工业协会
- 券商：Morgan Stanley / Goldman / 中信建投 / 东吴 / 华泰 / 招商
- 公司：招股书、季报、产能扩张公告
- 政府：工信部 / 发改委 / 财政部 / 美国能源部 / 欧盟委员会

### 消费品（新茶饮 / POP MART / SHEIN）
**关键源**：
- 用户洞察：尼尔森 / 凯度 / 艾瑞 / 数据精灵 / 易观
- 行业研报：东方证券 / 国海证券 / 招商商社团队
- 招股书：A 股 / 港股 / 美股
- 媒体：第一财经 / 财新 / 财经 / 商业周刊
- 平台数据：抖音 / 小红书 / 大众点评（爬虫 / 第三方监测）
- 海外：Euromonitor / Mintel

### 服务业 / 平台
**关键源**：
- 公司年报：DAU / MAU / take rate / GTV
- 监管：反垄断报告 / 数据安全
- 用户 review：App Store / 大众点评 / Yelp
- 学术：平台经济、双边市场研究

### 创新药 / 医疗
**关键源**：
- 临床数据：ClinicalTrials.gov / 中国药物临床试验登记 / WHO ICTRP
- 监管：FDA / NMPA / EMA / PMDA
- 数据库：Citeline (Pharma Intelligence) / Cortellis / GlobalData
- 论文：NEJM / Lancet / Nature Medicine / PubMed
- 行业媒体：FierceBiotech / Endpoints News / BioCentury

### 能源
**关键源**：
- 政策：DOE / BNEF / IRENA / IEA / 中国能源研究所
- 数据：BNEF (BloombergNEF) / Wood Mackenzie / Rystad Energy
- 公司：能源公司 IR + 项目招标公告

### Fintech / 稳定币
**关键源**：
- 监管：SEC / CFTC / Fed / FINRA / FCA / MAS / 央行
- 链上数据：Dune / Glassnode / Nansen / The Block
- 媒体：The Block / CoinDesk / Decrypt / Stratechery (web3 视角)
- 学术：BIS / IMF Working Paper

## 信息源 quality 评级

| Tier | 评级 | 例子 |
|---|---|---|
| **Tier 1** | 一手 / 权威 | 公司 IR / 监管文件 / 顶级期刊 / 头部投行（Goldman / MS / BNEF / IFR / IDC） |
| **Tier 2** | 专业转引 | 主流券商 / Bloomberg / Reuters / FT / WSJ / 第一财经 / 财新 / 行业垂直 |
| **Tier 3** | 参考 | 聚合站 / 行业博客 / 知乎专栏 / 36氪 / 量子位 |

**操作纪律**：核心论点必须有 Tier 1 + Tier 2 双重证据。
