# 写作风格指南 · Style Guide

> 这份报告最终交付给 **PE 老板和员工**。专业、克制、可追溯。

---

## 1. 措辞强度

### 软化强判断
| 强（避免） | 弱（推荐） |
|---|---|
| 必然 | 大概率 / 有较高概率 |
| 稳态 / 已定型 | 当前格局 |
| 全链垄断 | 主导 / 高份额 |
| 绝对主导 | 主导（高份额） |
| 世代级机会 | 历史级量级机会（前提：...） |
| 必将 | 有可能 / 假设... 将会 |
| 完全 / 全部 | 多数 / 大部分 |
| 颠覆 | 显著影响 / 重塑 |

### 概率给定
- ❌ "humanoid IRA 概率 40%"（单点概率拍脑袋）
- ✅ "20-50% 区间（依赖 Optimus 兑现度等变量）"
- ✅ "若 X 发生 → 概率 60%；若 X 未发生 → 20%"（条件概率）

### 时间表
- ❌ "2027 一定 PMF"
- ✅ "Base case 2027-2028 出现 PMF 案例；Bull case 2026 H2；Bear case 2030+"

---

## 2. 引用规范

### 每个数字 ≥ 1 个 URL
- 引用紧跟数字：`...全球出货 1.8 万台 [REF010]`
- 或文末 footnote：`[1] [2]`
- 链接到 References 章节的对应条目

### 不可追溯的处理
- `[UNSOURCED]` — 完全无来源，需 reviewer 补
- `[INFERRED]` — 基于其他数据推算（标明推算逻辑）
- `[UNDISCLOSED]` — 公司未披露（不是没有，是未公开）
- `[ESTIMATE]` — 分析师估算（标明假设）

### 引用句式
- 直接引用：`Brett Adcock 在 Time Oct 2025 访谈中说："..."`
- 转述：`Brett Adcock 公开表态在 10 年内每家都会有人形机器人（Time, Oct 2025）`
- 数据：`IDC 2025 报告显示全球出货 1.8 万台（同比 +508%）`

## 3. 数字与单位

### 标清楚口径
- ❌ "中国占全球 85%"（IDC vs GGII 口径不同）
- ✅ "中国占全球 80-95%（IDC 95% / GGII 85% 口径差异）"

### 区分时间口径
- ❌ "2030 全球出货 150-300 万台"（年度 vs 累计未区分）
- ✅ "2030 年度新增出货 25-80 万台 / 累计保有量 150-300 万台"

### 货币换算明示
- ❌ "宇树估值 $5B"
- ✅ "宇树估值 ¥120 亿（约 $16.7B，按 1 USD = 7.2 RMB）"

### 数学验算
- 定价公式当场算两次：`$25/h × 8h × 250 days = $50K/year`
- 收入 vs TAM 检验：单家公司不能占 TAM > 60-70%
- 复利公式 / CAGR 验算

---

## 4. 段落结构

### 每段最多 3 个关键信息
- 一段一论点
- 论点 → 证据 → 反驳处理 → 引申

### 表格优先于段落
- 数据型内容用表格（清晰、对比）
- 叙事型用段落

### 标题层级
- `h1` 章节
- `h2` 大节
- `h3` 小节
- `h4` 细分点（少用）

---

## 5. 章节内开篇规范

每个章节开头 3 句话内回答：
1. **这一章解决什么问题？**
2. **关键发现是什么？**
3. **读者读完应该知道什么？**

不要拐弯抹角，直接给结论 + 论据展开。

---

## 6. 禁忌（PE 老板看的报告）

### 元叙事禁忌
- ❌ "本章应用 Anthropic financial-services-plugins ic-memo skill 模板"
- ❌ "本节由 debate-critic agent 生成"
- ❌ "应用 unit-economics skill 模板..."
- ❌ "（已修正口径，见自审章节）"
- ✅ 直接呈现内容，不暴露生产过程

### 内部产物禁忌
- ❌ ERRATA / 自审章节进主报告
- ❌ "感谢 Agent X 的贡献" 类语言
- ❌ TODO / WIP / FIXME 留在交付物里

### Deal-level 工具禁忌（除非用户明确要求）
- ❌ IC Memo（智元 1-page 投决备忘）
- ❌ 投委会 Q&A 标准答案
- ❌ 31 条 PE Checklist
- ❌ 决策树（如何在三情景下决定）
- ❌ 组合配置建议（人民币 30% / 美元 15%）
- ❌ 投资优先级 ★★★★★ 矩阵

如果用户明确要求 → 放附录，明确标注"附录 A · PE 内部分析工具（与正文行业研究分开）"。

---

## 7. 视觉与排版

### KPI 数字
- 大字号 + 重色（如深蓝 / 红色）
- 简短标签
- 不超过 4-8 个 KPI 卡片

### 图表
- 柱图 / 饼图：占比 / 排行
- 折线：时间序列
- 雷达：多维对比
- 散点：风险×回报象限
- 时间轴：catalyst 日历
- Mermaid 流程图：产业链 / 决策树（如有）

### 信息盒
- 🟢 success-box：好消息 / 强项
- 🟡 insight-box：洞察 / 启示
- 🔵 info-box：补充说明
- 🟠 warning-box：警示 / 不确定性

---

## 8. 最终自查清单

报告交付前自查（不交给 user，内部 audit）：

- [ ] 所有数字带 URL 或 [UNSOURCED] / [INFERRED] / [UNDISCLOSED]
- [ ] 所有"必然 / 稳态 / 全链垄断" 已软化
- [ ] 所有概率给定改为区间 + 触发条件
- [ ] 时间口径明示（年度 vs 累计）
- [ ] 货币换算明示
- [ ] 数学公式验算两次
- [ ] 单家收入 vs TAM 检验
- [ ] 无元叙事（应用 X skill / debate-critic 等）
- [ ] PE deal-level 工具仅在附录
- [ ] 无 ERRATA / 自审章节进主报告
- [ ] 顶尖人物每条 thesis 带 URL
- [ ] 反方声音至少 3 条（不只是 cheerleader）
- [ ] References DB 完整、tier 分级
